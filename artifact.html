AI and Machine Learning Algorithms – Visual Framework

Introduction

Machine Learning (ML) allows computers to learn from data and make decisions without being programmed for every task.

ML algorithms fall into two main categories:

  • Supervised Learning – trained on labeled data to make predictions
  • Unsupervised Learning – finds hidden patterns in unlabeled data

These algorithms are applied across four key domains:

  • Tabular Data
  • Computer Vision
  • Natural Language Processing (NLP)
  • Generative AI

Algorithm Framework

Algorithm Algorithm Type Application Domain Brief Explanation Example Use Case
Decision Tree Supervised Learning Tabular Data Uses logical decision rules to classify or predict outcomes. Loan approval prediction
Random Forest Supervised Learning Tabular Data Combines multiple decision trees to improve prediction accuracy. Fraud detection
Linear Regression Supervised Learning Tabular Data Predicts continuous numerical values based on relationships between variables. House price prediction
Support Vector Machine (SVM) Supervised Learning Tabular Data Separates data into categories using decision boundaries. Spam email classification
K-means Clustering Unsupervised Learning Tabular Data Groups similar data into clusters based on similarity. Customer segmentation
Principal Component Analysis (PCA) Unsupervised Learning Tabular Data Reduces data dimensions while preserving important information. Data compression
Convolutional Neural Network (CNN) Supervised Learning Computer Vision Uses deep learning layers to process and recognize images. Facial recognition
YOLO (You Only Look Once) Supervised Learning Computer Vision Detects multiple objects in real time within images and videos. Self-driving cars
BERT Supervised Learning Natural Language Processing Understands language context and word relationships. Sentiment analysis
GPT (Generative Pre-trained Transformer) Generative AI NLP / Generative AI Generates human-like text using transformer architecture. ChatGPT
GAN (Generative Adversarial Network) Generative AI Generative AI Uses competing neural networks to generate realistic content. AI-generated images
Stable Diffusion Generative AI Generative AI Creates images from text prompts using diffusion models. AI art generation

Why Are Algorithms Chosen?

The right algorithm depends on the type of data, the problem being solved, and the desired output. Tabular problems often use tree-based or statistical models, image tasks require CNNs, language tasks use transformers, and content creation relies on generative AI models like GANs and diffusion models.

Reflection

This assignment helped me understand that no single algorithm works for every situation. Each algorithm is designed for a specific type of data and task. What stood out most to me was how generative AI models such as GANs and diffusion models are fundamentally different from predictive algorithms because they do not just classify data — they can also generate entirely new content. Understanding these differences is important when selecting the right AI tool for solving real-world business and technology problems.
